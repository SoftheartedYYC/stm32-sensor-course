# hcsr04 —— HC-SR04 超声波测距

用 **TIM1_CH1 输入捕获**测 Echo 高电平宽度：Trig 触发一次，Echo 变高到变低的时间就是声波往返时间，
距离 = 宽度(us) / 58。

| 项目 | 内容 |
|---|---|
| 头文件 | `hcsr04.h` |
| 引脚 | Trig = PB12（推挽输出）；Echo = PA8（TIM1_CH1） |
| 依赖 | 测量函数要 `delay_init()`（等回波时用 `delay_us`） |
| 资源 | TIM1 CH1 输入捕获 + 2 个 GPIO |

## 接线

| 模块引脚 | MCU | 说明 |
|---|---|---|
| VCC | 5V | 模块按 5V 供电 |
| GND | GND | 必须和 MCU 共地 |
| Trig | **PB12** | 推挽输出，给 ≥10µs 高电平 |
| Echo | **PA8** | TIM1_CH1，输入捕获 |

> Echo 是 5V 输出。PA8 是 **5V 容忍（FT）** 脚，可以直接接；
> 想更稳妥就串 1kΩ，再在 Echo 与 GND 之间并 2kΩ 分压到 3.3V。
> Trig 用 3.3V 高电平大多数模块都能触发；如果实测不触发，再加一级电平转换。

## 原理与定时器

| 项目 | 值 |
|---|---|
| 触发脉宽 | 12µs（手册要求 ≥10µs） |
| TIM1 时钟 | 72MHz |
| 预分频 | 71 → 1MHz，1 个计数 = 1µs |
| 计数范围 | 16 位，65.5ms 溢出 |
| 捕获方式 | CH1 直接映射 TI1，先上升沿、再切下降沿 |
| 距离换算 | cm = 宽度(µs) / 58，mm = 宽度(µs) × 10 / 58 |
| 量程 | 2~400cm（对应 116~23200µs） |

## 函数

| 函数 | 说明 |
|---|---|
| `void HCSR04_Init(void)` | Trig 推挽输出、Echo 下拉输入、TIM1_CH1 捕获中断 |
| `uint8_t HCSR04_ReadUs(uint16_t *width_us)` | 测一次，返回原始回波宽度；1 = 成功，0 = 超时 |
| `uint8_t HCSR04_ReadCm(uint16_t *cm)` | 测一次，返回 2~400cm；超量程/超时返回 0 |
| `uint8_t HCSR04_ReadMm(uint16_t *mm)` | 测一次，返回 20~4000mm；超量程/超时返回 0 |

读取是**阻塞**的：正常情况下阻塞时间等于回波宽度（几毫秒），
最坏等 10ms（没有上升沿）+ 60ms（没有下降沿）。

## 示例

```c
#include "delay.h"
#include "hcsr04.h"

uint16_t cm;

delay_init();
HCSR04_Init();

while (1)
{
    if (HCSR04_ReadCm(&cm))
    {
        /* cm = 2~400 */
    }

    delay_ms(100);   /* 两次测量至少间隔 60ms，100ms 比较稳 */
}
```

## 注意

- 两次测量间隔要 **≥60ms**，否则上一次的回波会干扰下一次。
- 超出 2~400cm、正对吸音材料、障碍物太斜，都可能读不到；`ReadCm()` 返回 0，不要当成 0cm 用。
- Echo 固定接 **PA8 / TIM1_CH1**：换通道要改中断里的 `TIM_IT_CC1`、`TIM_GetCapture1` 和极性函数，
  不是只改头文件宏就行；Trig 倒是可以随便换空闲 GPIO。
- TIM1 被这个模块占用；工程里没有别的模块用 TIM1。
- `TIM1_CC_IRQHandler` 只在这里定义，别在 `stm32f10x_it.c` 里重复写。
- 要更稳可以连续测 3 次取中间值，或在主循环里 100ms 读一次、不阻塞其它显示。
- 本工程 `main.c` 目前没有初始化超声波；要用的话把上面示例的 `HCSR04_Init()` 和读取加到 `main.c` 里即可。
